02

How the algorithm works

TABULAR MINIMIZATION

Quine–McCluskey is a systematic method for minimizing Boolean functions. It is especially useful when you want a repeatable tabular process instead of visually grouping cells.

1 · Convert to binary

Write each entered index using exactly the selected number of variables. Keep permitted don't-care terms in the same list.

2 · Group by 1-count

Place terms into groups according to how many 1s appear in their binary pattern. Only neighboring groups need comparison.

3 · Combine terms

Combine two patterns only when they differ in exactly one bit. Replace that differing bit with a dash (–).

4 · Repeat the rounds

Group and compare the newly combined patterns again until no more combinations can be made.

5 · Find prime implicants

Any valid term that cannot be combined further becomes a prime implicant. It represents a product term covering multiple input combinations.

6 · Build the chart

List prime implicants as rows and required minterms/maxterms as columns. A mark shows which required index each implicant covers.

7 · Select a minimum cover

Choose essential implicants first, then select the remaining implicants needed to cover every required index with a low-cost expression.

8 · Write the equation

Translate each selected binary pattern into a Boolean term. A dash means that variable is eliminated because it changes within the group.

How to read a pattern: For variables A, B, C, the pattern 1–0 means A = 1, C = 0, and B can be either value. Its SOP term is A C̅.
